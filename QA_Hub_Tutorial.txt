4. HALAMAN DASHBOARD (/dashboard)
-----------------------------------
Ringkasan statistik dari Jenkins:
  - Total builds
  - Success rate
  - Recent activity


5. HALAMAN SCRIPTS (/scripts)
-------------------------------
Daftar semua script Playwright dari Docker volume:
  automation_scripts → /data/automation/tests/

Script dikelompokkan per folder:
  - root            → tests/
  - learning-course → tests/learning-course/
  - okr             → tests/okr/

5a. Mencari Script
    Ketik di search bar untuk filter real-time berdasarkan nama file.

5b. Menjalankan Script
    1. Klik tombol "Run" di baris script yang diinginkan.
    2. Pilih konfigurasi (browser, environment) jika muncul dialog.
    3. Browser otomatis pindah ke halaman Live Log Viewer.

    CATATAN: Tombol Run di-disable saat ada script lain yang sedang running.

5c. Upload Script Baru
    1. Klik tombol "Upload Script" di kanan atas halaman.
    2. Pilih folder tujuan (root, learning-course, okr, dll).
    3. Pilih file .spec.ts dari komputer.
    4. File tersimpan di Docker volume: /data/automation/tests/{folder}/

    CATATAN: Hanya file .spec.ts yang diizinkan.


6. HALAMAN LIVE LOG VIEWER (/run/[buildId])
--------------------------------------------
Menampilkan output nyata dari proses Playwright secara real-time.

6a. Informasi Header
    - Build ID  : ID unik (format: RUN-XXXXX)
    - Status    : running / success / failure / aborted
    - Script    : nama file yang dijalankan
    - Timer     : elapsed time

6b. Console Output
    Log mengalir real-time via Server-Sent Events (SSE).
    Kode warna:
      Biru   = INFO / "Running"
      Hijau  = PASSED / ✓
      Merah  = FAILED / Error / ×
      Kuning = WARNING
      Abu-abu = output biasa

    Auto-scroll ke baris terbaru.

6c. Tombol Abort
    Muncul saat status "running".
    Klik untuk menghentikan proses dan abort Jenkins build.

6d. Tombol View Report
    Muncul setelah build selesai (status: success/failure/aborted).
    Klik untuk melihat HTML Report dari Playwright.


7. HALAMAN HISTORY (/history)
------------------------------
Menampilkan tabel riwayat semua run dari Jenkins.

Data diambil real-time dari Jenkins API — kosong jika Jenkins restart.

Kolom tabel:
  - Build ID   : RUN-XXX (klik → ke Log Viewer)
  - Script     : nama file yang dijalankan
  - Status     : success / failure / running
  - Environment: Staging
  - Browser    : chromium
  - Duration   : waktu eksekusi
  - Date       : waktu mulai
  - Actions    : Logs / Report / Jenkins

Tombol aksi per baris:
  - Logs    → halaman Live Log Viewer (/run/RUN-XXX)
  - Report  → halaman Report Viewer (/reports/RUN-XXX)
  - Jenkins → buka build di Jenkins CI (tab baru)


8. HALAMAN REPORT VIEWER (/reports/[buildId])
----------------------------------------------
Menampilkan Playwright HTML Report hasil test run.

Setiap build disimpan terpisah:
  /data/reports/playwright-html/{BUILD_NUMBER}/

Tombol di header:
  - Back          : kembali ke History
  - HTML Report   : buka report di iframe bawah
  - Open in Tab   : buka report di tab baru
  - Jenkins       : buka build di Jenkins (tab baru)
  - Export Excel  : download laporan dalam format .xlsx

8a. Export Excel
    Klik tombol "Export Excel" untuk download file .xlsx.
    File berisi 4 sheet:

    Sheet 1: 📊 Ringkasan
      - Status keseluruhan (PASSED / ADA KEGAGALAN)
      - Statistik: total, passed, failed, skipped, flaky, durasi
      - Informasi eksekusi: proyek, waktu mulai, environment, browser
      - Kesimpulan eksekutif

    Sheet 2: 📋 Daftar Test Case
      - Semua test case dalam satu tabel
      - Kolom: TC ID, Suite/File, Nama Skenario, Status, Durasi,
               Browser, Waktu Mulai, Catatan
      - Status color-coded: hijau (PASSED), merah (FAILED),
                            kuning (FLAKY), kuning muda (SKIPPED)
      - Rekap otomatis: Total, Passed, Failed, Skipped, Flaky, %

    Sheet 3: 🔍 Detail Langkah
      - Step-by-step dari setiap test case
      - Header per-TC dengan durasi
      - Kolom: TC ID, No., Aksi, Status, Catatan Error

    Sheet 4: 🐛 Bug & Failure Log
      - Hanya test yang FAILED atau FLAKY
      - Kolom: TC ID, Nama Test, Error Message, Status,
               Langkah Reproduce, Assignee, Priority
      - Jika semua passed: pesan "Tidak ada kegagalan"

    Nama file download: playwright-report-{buildId}.xlsx

    CATATAN: Fitur ini membutuhkan report.json yang dihasilkan
    oleh Playwright JSON reporter. Build lama (sebelum fitur ini
    aktif) tidak mendukung export Excel.


9. MENJALANKAN SCRIPT DARI JENKINS (Manual)
---------------------------------------------
Selain dari UI, script bisa dijalankan langsung dari Jenkins:

1. Buka http://localhost:8080/jenkins
2. Login dengan admin / admin123
3. Klik job "run-playwright-script"
4. Klik "Build with Parameters"
5. Isi parameter:
   - SCRIPT_PATH : contoh: tests/dashboard.spec.ts
   - BROWSER     : chromium / firefox
   - BASE_URL    : contoh: https://hris-staging.kantorku.id/
6. Klik "Build"

Log bisa dilihat di Console Output Jenkins atau di
halaman Report Viewer setelah build selesai.


10. UPDATE KODE NEXT.JS (PENTING)
-----------------------------------
Karena Docker volume /app/.next bersifat persisten, cara
update kode berbeda dari biasa:

CARA YANG BENAR:
  1. Edit file di host (frontend/src/...)
  2. Build ulang di dalam container:
       docker exec webqa-nextjs-1 sh -c "cd /app && pnpm build"
  3. Restart service:
       docker compose restart nextjs

JANGAN pakai docker compose build — tidak akan update .next volume.

Pengecualian: file di public/ (termasuk template Excel) langsung
terbaca tanpa rebuild karena di-serve dari bind mount.


11. STORAGE & DATA
-------------------
Script dan Report disimpan di Docker volumes (tidak di folder lokal):

Volume: webqa_automation_scripts
  - Path di container: /data/automation/
  - Berisi: script .spec.ts

Volume: webqa_reports_data
  - Path di container: /data/reports/
  - Berisi: playwright-html/{BUILD_NUMBER}/index.html
             playwright-html/{BUILD_NUMBER}/report.json

Volume: webqa_jenkins_home
  - Path di container: /var/jenkins_home
  - Berisi: Jenkins job config, build history

CATATAN: History run kosong setelah Jenkins container di-restart
(Jenkins data tersimpan di volume, tapi UI Next.js fetch ulang
dari Jenkins API).


12. PERINTAH DOCKER UMUM
--------------------------
  docker compose up -d              → start semua service
  docker compose down               → stop (data tetap)
  docker compose down -v            → stop + hapus semua volume
  docker compose ps                 → cek status container
  docker compose restart nextjs     → restart Next.js saja
  docker compose restart jenkins    → restart Jenkins saja
  docker logs webqa-nextjs-1 -f     → live log Next.js
  docker logs webqa-jenkins-1 -f    → live log Jenkins


13. TROUBLESHOOTING
--------------------

Q: Build gagal / script tidak berjalan?
A: Cek apakah playwright-runner image sudah ada:
     docker images | grep playwright-runner
   Jika tidak ada:
     docker compose build playwright-runner

Q: History kosong setelah restart?
A: Jenkins mempertahankan data di volume jenkins_home.
   Jika history benar-benar hilang, berarti volume ikut terhapus.
   Pastikan tidak pakai "docker compose down -v".

Q: Report tidak muncul / halaman putih?
A: Pastikan build sudah menghasilkan report.json.
   Build yang dijalankan sebelum JSON reporter aktif tidak punya
   file ini. Jalankan ulang script tersebut.

Q: Tombol Export Excel gagal (error 404)?
A: report.json tidak ada untuk build tersebut.
   Jalankan ulang script untuk generate report baru.

Q: Kode yang diubah tidak ter-apply setelah restart Docker?
A: Ikuti prosedur update kode di §10 — build di dalam container.

Q: Log SSE tidak update?
A: Refresh halaman. SSE reconnect otomatis.

Q: Upload script gagal?
A: Pastikan file berekstensi .spec.ts (bukan .ts biasa).

Q: Jenkins tidak bisa diakses?
A: Tunggu sekitar 30-60 detik setelah docker compose up.
   Jenkins butuh waktu startup. Cek dengan:
     docker logs webqa-jenkins-1 --tail 30
