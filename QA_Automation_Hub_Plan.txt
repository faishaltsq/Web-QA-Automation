PROJECT PLAN: QA AUTOMATION HUB
Revised: 2026-04-29
==============================================================


1. OVERVIEW
-----------
Web dashboard internal untuk tim QA — jalankan script automation
Playwright langsung dari browser tanpa perlu buka terminal.

Status saat ini: LOKAL, berjalan di mesin developer.
Target berikutnya: hosted di server/VPS agar bisa diakses tim.


2. ARSITEKTUR SAAT INI (AKTUAL)
--------------------------------
Layer          | Teknologi
---------------|--------------------------------------------------
Frontend       | Next.js 16 (App Router) + TailwindCSS v4 + Shadcn
API            | Next.js Route Handlers (bagian dari frontend)
Execution      | Node.js child_process.spawn (langsung dari server)
Log Streaming  | Server-Sent Events (SSE) via ReadableStream
Storage        | In-memory (Map) — hilang saat server restart
Script Files   | Filesystem lokal (Automation Kantorku/tests/)
Auth           | Tidak ada (sengaja di-skip untuk fase ini)
Database       | Tidak ada

Tools yang dipakai saat runtime:
  - npx playwright test  → executor script
  - Chromium             → browser (via Playwright)
  - --reporter=list      → output real-time ke stdout


3. ARSITEKTUR TARGET (HOSTED)
------------------------------
Layer          | Teknologi
---------------|--------------------------------------------------
Frontend       | Next.js (sama, deploy ke VPS)
Backend        | FastAPI (Python) — opsional, bisa tetap Next.js API
Database       | SQLite (cukup untuk tim kecil) atau PostgreSQL
Auth           | Session sederhana atau JWT
Execution      | Langsung child_process ATAU Jenkins (opsional)
Log Streaming  | SSE (sama)
Script Storage | Filesystem di server atau Git repo
Reports        | Allure (generate setelah run selesai)
Infra          | VPS + Nginx reverse proxy
SSL            | Let's Encrypt (certbot)
