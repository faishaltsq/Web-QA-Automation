TOOLS & ARSITEKTUR — QA AUTOMATION HUB
Update: 2026-04-30

1. OVERVIEW
-----------
QA Automation Hub adalah sistem CI/CD untuk menjalankan automated
test menggunakan Playwright, dengan interface web berbasis Next.js
dan Jenkins sebagai orchestrator.

3. DETAIL PER TOOL
------------------

3.1 NEXT.JS (FRONTEND)
Port: 3000
Path: C:\Users\faishaltsq\Documents\Kerjaan\WebQA\frontend\

Fungsi:
  - Interface GUI untuk user
  - Upload script automation
  - Trigger build ke Jenkins
  - Lihat history dan report
  - Stream log real-time

API Endpoints:
  POST /api/run          → Trigger Jenkins build
  GET  /api/history      → Ambil daftar build dari Jenkins
  GET  /api/logs/[id]    → Stream log via SSE
  POST /api/scripts/upload → Upload file .spec.ts
  GET  /api/scripts       → List semua script
  GET  /api/reports/[id] → Ambil HTML report


3.2 JENKINS (CI/CD SERVER)
Port: 8080 (http://localhost:8080/jenkins)
Path: C:\Users\faishaltsq\Documents\Kerjaan\WebQA\jenkins\

Fungsi:
  - Menerima build request dari Next.js
  - Menyimpan job configuration
  - Eksekusi Docker container untuk test
  - Archive artifact (HTML report)

Job: run-playwright-script
Parameters:
  - SCRIPT_PATH  : Path ke script (contoh: dashboard.spec.ts)
  - BROWSER      : chromium / firefox (default: chromium)
  - BASE_URL     : URL target test (contoh: https://hris-staging.kantorku.id/)
  - BUILD_NUMBER : Nomor build Jenkins (auto-generated)

Kredensial:
  Username: admin
  Password: admin


3.3 PLAYWRIGHT RUNNER (DOCKER CONTAINER)
Image: playwright-runner:latest
Path: C:\Users\faishaltsq\Documents\Kerjaan\WebQA\playwright-runner\

Fungsi:
  - Eksekusi Playwright test berdasarkan script
  - Generate HTML report
  - Simpan report ke Docker volume

Environment Variables (diterima dari Jenkins):
  - SCRIPT_PATH   → Script yang akan dijalankan
  - BROWSER       → Browser yang digunakan
  - BASE_URL      → Target aplikasi untuk test
  - BUILD_NUMBER  → Untuk folder report unique

Command yang dijalankan:
  npx playwright test $SCRIPT_PATH \
    --reporter=list,html \
    --project=$BROWSER \
    --timeout=60000


3.4 DOCKER & DOCKER COMPOSE
Fungsi:
  - Containerize semua services
  - Volume management untuk persistent data
  - Network untuk komunikasi antar container

Network: webqa_qa-hub-network (bridge driver)

6. DOCKER COMPOSE CONFIG
------------------------

File: C:\Users\faishaltsq\Documents\Kerjaan\WebQA\docker-compose.yml

version: '3.8'

services:
  nextjs:
    build: ./frontend
    ports:
      - "3000:3000"
    environment:
      - JENKINS_URL=http://jenkins:8080/jenkins
      - JENKINS_USER=admin
      - JENKINS_PASS=admin
    volumes:
      - ./frontend:/app              # kode Next.js (hot reload)
      - /app/node_modules
      - /app/.next
      - automation_scripts:/data/automation
      - reports_data:/data/reports
    networks:
      - qa-hub-network

  jenkins:
    build: ./jenkins
    ports:
      - "8080:8080"
    volumes:
      - jenkins_home:/var/jenkins_home
      - automation_scripts:/data/automation   # share dengan nextjs
      - reports_data:/data/reports            # share dengan nextjs
      - /var/run/docker.sock:/var/run/docker.sock
    environment:
      - JENKINS_OPTS=--prefix=/jenkins
    networks:
      - qa-hub-network

volumes:
  jenkins_home:
  automation_scripts:    # Named volume
  reports_data:          # Named volume

networks:
  qa-hub-network:
    driver: bridge


7. STORAGE LOCATION

  Linux:   /var/lib/docker/volumes/

Cek lokasi volume:
  docker volume inspect webqa_automation_scripts
  docker volume inspect webqa_reports_data

Lokasi actual (dari inspect):
  "Mountpoint": "/var/lib/docker/volumes/webqa_automation_scripts/_data"


8. MENGUBAH KE LOCAL FOLDER (BIND MOUNT)
----------------------------------------

Jika ingin script tersimpan di folder lokal project:

1. Buat folder di root project:
   automation-scripts/

2. Edit docker-compose.yml:

   volumes:
     # SEBELUM (Named Volume)
     - automation_scripts:/data/automation

     # SESUDAH (Bind Mount)
     - ./automation-scripts:/data/automation

3. Restart container:
   docker compose down
   docker compose up -d

EFFECT:
  Path lokal: C:\Users\faishaltsq\Documents\Kerjaan\WebQA\automation-scripts\
  Path di container: /data/automation/tests\

  File bisa dilihat langsung di Windows Explorer.

12. SECURITY NOTES
-----------------

- Jenkins tidak memiliki authentication external (berbasis container)
- API /api/run tidak require authentication
- Volume adalah shared storage antar containers
- Docker socket di-mount ke Jenkins container (docker-in-docker)


13. TROUBLESHOOTING
-------------------

Masalah: Report sama untuk semua build
Cause: BUILD_NUMBER tidak dikirim ke container
Solusi: Cek config.xml Jenkins job, pastikan ada -e BUILD_NUMBER

Masalah: Script tidak ditemukan saat run
Cause: Volume automation_scripts tidak ter-mount dengan benar
Solusi: docker compose down && docker compose up -d

Masalah: Cannot connect to Jenkins
Cause: Jenkins belum selesai startup
Solusi: Tunggu 30 detik, atau restart: docker compose restart jenkins
