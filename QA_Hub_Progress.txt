1. APA INI?
=============================================================
Web dashboard untuk menjalankan script automation Playwright
langsung dari browser — tanpa perlu buka terminal.

Tim QA bisa:
  - Lihat semua script yang ada
  - Klik "Run" → script berjalan via Jenkins + Docker
  - Lihat live output/log di browser secara real-time
  - Lihat status: passed / failed / aborted
  - Upload script Playwright dari browser
  - Lihat HTML Report hasil Playwright
  - Export laporan ke Excel (.xlsx) sesuai template standar

Ini BUKAN SaaS publik. Ini internal tool untuk tim QA.
Target: bisa dihosting di VPS dengan Jenkins + Docker.

2. STACK TEKNOLOGI
=============================================================
Frontend   : Next.js 16.2.4 (App Router) + TypeScript
UI         : TailwindCSS v4 + Shadcn (via @base-ui/react, BUKAN Radix)

PENTING — Shadcn di proyek ini BUKAN versi standard:
  - Pakai @base-ui/react, BUKAN @radix-ui

3. ARSITEKTUR TARGET (JENKINS + DOCKER)
=============================================================

Flow:
  Browser → Next.js API → Jenkins (trigger job) → Docker container (run Playwright)
                                              ↓
                                       Results + Artifacts
                                              ↓
                                    HTML report + report.json
                                              ↓
                                    Next.js Report Viewer
                                              ↓
                                    Export Excel (.xlsx)

Services (docker-compose):
  - nextjs            : Port 3000 (Frontend + API)
  - jenkins           : Port 8080 (Job management) → http://localhost:8080/jenkins
  - playwright-runner : Docker image untuk execute tests (via Jenkins)

Docker Images:
  - webqa-nextjs:latest       (Next.js)
  - playwright-runner:latest  (Node.js + Playwright + Chromium on Debian)
  - webqa-jenkins:latest      (Jenkins LTS + plugins)

Jenkins Job:
  - Job name: run-playwright-script
  - Trigger: via REST API (buildWithParameters)
  - Parameter: SCRIPT_PATH, BROWSER, BASE_URL, BUILD_NUMBER
  - Execute: docker run playwright-runner
  - Post-build: archive artifacts

5. DOCKER QUIRK PENTING — WAJIB BACA
=============================================================

docker-compose.yml punya volume anonim untuk /app/.next:

  volumes:
    - ./frontend:/app        # bind mount — source files live di sini
    - /app/node_modules      # anonim volume
    - /app/.next             # anonim volume ← MASALAH INI

Volume /app/.next PERSIST antar rebuild. Jika kode Next.js diubah
di host, perlu BUILD ULANG DI DALAM container — bukan docker compose build.

CARA UPDATE KODE NEXT.JS YANG BENAR:
  1. Edit file di host (frontend/src/...)
  2. Build di dalam container:
       docker exec webqa-nextjs-1 sh -c "cd /app && pnpm build"
  3. Restart:
       docker compose restart nextjs

JANGAN pakai:
  docker compose build nextjs   ← image baru, tapi .next volume tetap lama
  docker compose up --build     ← sama, tidak efektif

7. API ROUTES
=============================================================

GET  /api/scripts
  Response: { scripts: [{ name, relPath, folder, sizeKb, updatedAt }] }

POST /api/run
  Body: { script: "relative/path.spec.ts", browser?: "chromium" }
  Response: { runId: "RUN-XXXXX" }
  Action: trigger Jenkins job "run-playwright-script"

DELETE /api/run
  Body: { runId: "RUN-XXXXX" }
  Action: abort Jenkins build

GET  /api/logs/[runId]
  Response: text/event-stream
  Source: Jenkins console progressiveText bridge

GET  /api/history
  Response: { builds: [...] }
  Source: Jenkins API /job/run-playwright-script/api/json

GET  /api/reports/[buildId]
  Response: { hasReport: boolean, buildNumber: string }

GET  /api/reports/[buildId]/excel
  Response: .xlsx file download
  Source: /data/reports/playwright-html/{num}/report.json

GET  /api/reports/[buildId]/[filePath]
  Response: file content (HTML/JS/CSS untuk serve Playwright report)
